# UI Icons (`ui/assets/icons`)

Vector icons (SVG) used by Qt Style Sheets (QSS) and UI components.

## Files

- **`chevron_down.svg`**: Modern chevron-down vector icon for `QComboBox` and `QAbstractSpinBox` down arrows.
- **`chevron_up.svg`**: Modern chevron-up vector icon for `QAbstractSpinBox` up arrows.
