# Project Rules & Guidelines

## Git Commit Protocol
- **Automatic Commits**: After completing any specific task, feature modification, bug fix, or refactoring, execute a `git commit` for the affected files.
- **Commit Naming**: Create clear, descriptive conventional commit messages (e.g., `feat: ...`, `fix: ...`, `refactor: ...`) detailing the specific changes made.
- **Scope Discipline**: Only stage and commit files related to the specific work unit performed.
